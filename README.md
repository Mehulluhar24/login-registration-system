# 🔐 Login & Registration System

## 📌 About The Project

The Login & Registration System is a web-based application designed to provide a simple and user-friendly authentication experience.

It allows users to create an account and log in using their registered credentials.

## ✨ Features

- User Registration
- User Login
- User Authentication
- Form Validation
- User-Friendly Interface
- Responsive Design
- Secure Password Handling 

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and design
- **JavaScript** – Client-side validation and interactivity
- **PHP** – Backend functionality
- **MySQL** – Database management

## 🚀 Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/login-registration-system.git
```

2. Move the project folder into XAMPP's `htdocs` directory.

3. Start Apache and MySQL from XAMPP.

4. Import the database into phpMyAdmin if your project uses MySQL.

5. Open your browser and visit:

```text
http://localhost/login-registration-system/
```
